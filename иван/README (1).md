# Рефакторинг лендинга Ивана Серко

Структура проекта после рефакторинга:

```
serko-portfolio/
├── index.html        # семантическая разметка, без инлайн-стилей и скриптов
├── css/
│   └── styles.css    # все стили, каскад сгруппирован по блокам
└── js/
    └── app.js        # весь интерактив, модульная структура
```

## Что изменено

### Разделение ответственности
- HTML / CSS / JS вынесены в отдельные файлы (единый файл → три файла).
- Инлайн-стили (`style="color:var(--green)"` и т.п.) заменены классами-модификаторами (`tag-green`, `tag-steel`, `tag-emerald`, `.highlight`).

### HTML
- Семантика: `nav` с `aria-label`, `type="button"` у кнопок, `aria-expanded` / `aria-controls` у бургера.
- Убран `<base target="_blank">` — это анти-паттерн (ломает якорные ссылки, мешает UX). Внешние ссылки открываются в новой вкладке точечно, с `rel="noopener"`.
- Облачная защита email (Cloudflare `data-cfemail` + скрипт `/cdn-cgi/...`) заменена обычными `mailto:333742917@mail.ru` — обфускация давала ложную безопасность (email легко декодируется) и создавала зависимость от Cloudflare.
- Добавлен `loading="lazy"` на фото.

### CSS
- Секционные комментарии, единый переиспользуемый `--ease-out`.
- Мобильное меню — через отдельный блок `.mobile-menu` (раньше позиционировалось костыльным `top: calc(100% + 220px)` и инлайн-стилями из JS).
- Переход `.scenario-card` описан один раз в CSS (раньше назначался из JS на каждое переключение).
- Поддержка `prefers-reduced-motion`: отключены анимации появления и скролл.
- Анимации переименованы в `fade-in-up` / `fade-in-down` (дефисы — валидные имена для `@keyframes`).

### JS
- `'use strict'`, конфигурация вынесена в `CONFIG`, данные сценариев — в единый массив `SCENARIOS`.
- Никаких глобальных переменных: логика инкапсулирована в классы `ParticleField` и `ScenarioSwitcher`, остальное — в модулях-инициализаторах.
- Canvas с поддержкой `devicePixelRatio` — чёткая графика на Retina/мобильных экранах (раньше был размытый).
- События через `DOMContentLoaded` + `defer`, слушатели с `bind` (без утечек контекста), `{ passive: true }` для touch.
- `IntersectionObserver` отписывается после первого показа блока.
- Мобильное меню: класс `.open` + смена иконки и `aria-expanded`; закрывается после клика по ссылке.
